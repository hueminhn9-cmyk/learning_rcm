# Hướng Dẫn Khởi Chạy Dự Án

### 1. Cài đặt thư viện
```bash
pip install -r requirements.txt
```

### 2. Khởi tạo dữ liệu (Chỉ chạy 1 lần đầu)
```bash
python seed_multi_subject.py
```

### 3. Khởi chạy ứng dụng
```bash
python main.py
```
